# Night Current demo

The bounce beginners aim for while following `BEGINNER_GUIDE.md` or the in-app tutorial.

**File:** `demo/NightCurrent-Demo.wav`  
(Built by bouncing the same tutorial project used in tests.)

| | |
|---|---|
| BPM | 128 |
| Style | Dark techno |
| Chords | Cm → Ab → Eb → Bb |
| Length | 16 bars |

## Layout

1. Bars 1–2 — sparse kick / bass  
2. Bars 3–4 — full groove  
3. Bars 5–8 — main synth hook  
4. Bars 9–12 — counter + arp  
5. Bars 13–16 — hook returns bigger
